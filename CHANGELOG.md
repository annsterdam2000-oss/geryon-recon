# Changelog

Все значимые изменения в проекте Geryon Recon.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.0.0/),
и проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.3.0] - 2026-10-31

### Added
- Полноценная панель управления с навигацией (`/menu`, `/panel`, `/about`).
- Сбор и агрегация результатов по составным задачам (`username`).
- Прогресс-бар для составных задач (подсчет `done` и `failed` подзадач).
- WebSocket-уведомления для мгновенного обновления панели.

### Fixed
- Восстановлена база данных и схема хранения (JSON) после случайного удаления.
- Починена логика `recompute_parents`: родительская задача больше не падает в `failed`, если хотя бы один сайт недоступен.
- Исправлен редирект с корня на панель.
- Устранены ошибки импорта в `logic.py` и `state.py`.

### Changed
- Состояние (`state.py`) теперь хранит `progress_done` и `progress_failed` для фронтенда.
- Статика теперь отдается по прямым путям, а не через `/static`.

## [1.2.0] - 2026-10-28

### Добавлено
- **Валидация задач:** Сервер теперь отклоняет запросы с неизвестными типами задач (HTTP 400).
- **Повторная отправка:** Агент делает до 5 попыток отправить результат при сбоях сети.
- **Защита от дублей:** Сервер игнорирует повторные результаты для уже завершенных задач.
- **Конфигурация:** Адрес сервера и токен вынесены в `.env` файл (`GERYON_SERVER_URL`).

### Исправлено
- **Синхронизация БД:** При удалении агента он теперь корректно удаляется из SQLite.
- **Восстановление очереди:** При перезапуске сервера «зависшие» задачи возвращаются в статус `pending`.
- **Интерфейс:** Панель теперь показывает всплывающие окна (`alert`) при ошибках сервера, а не просто зависает.

## [1.1.0] - 2026-10-21

### Безопасность (Security)
- **Аутентификация API:** Внедрена проверка API-токена (заголовок `X-API-Key`) для всех критических эндпоинтов сервера (регистрация агентов, heartbeat, отправка результатов, создание и удаление задач).
- **Защита панели:** Веб-интерфейс теперь запрашивает пароль при загрузке и автоматически подставляет токен во все запросы (`fetch`).
- **Конфигурация:** Токен вынесен в переменные окружения (`.env`), чтобы секреты не попадали в репозиторий.

### Исправлено (Fixed)
- **Обработка HTTP-ошибок:** Модули `geo`, `ip`, `person`, `domain` и `email` теперь корректно обрабатывают ответы серверов с ошибками (4xx, 5xx), а также таймауты и невалидный JSON. Агент больше не падает при недоступности внешних API.
- **Nominatim / Overpass:** Добавлена обработка специфических ошибок (429 Rate Limit, 504 Timeout) для бесплатных гео-сервисов.
- **GitHub API:** Добавлена проверка на превышение лимита запросов (403 Rate Limit) при поиске пользователей.

## [1.0.0] - 2026-09-20

### Добавлено
- **Первоначальный релиз:** Сервер на FastAPI, агенты-воркеры, веб-панель на vanilla JS.
- **10 OSINT-модулей:** `email`, `email_reg`, `domain`, `username`, `ip`, `phone`, `person`, `telegram`, `geo`, `exif`.
- **Модуль мониторинга:** `sysinfo` для сбора телеметрии железа через LibreHardwareMonitor (LHM).
- **Отказоустойчивость:** Механизм возврата задач в очередь при падении агента, автоматический reconnect.
- **Уведомления:** Интеграция с Discord Webhook для оповещения о завершении задач.
- **База данных:** Сохранение состояния задач и ботов в SQLite.
- **Признание:** Модуль `sysinfo` включен в публичный индекс XERJ Corpus Hub.
