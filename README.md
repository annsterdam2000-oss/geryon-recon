# Geryon Recon

 _Distributed OSINT framework. Three bodies, one purpose._

> Named after **Geryon** — the three-bodied king of Tartessos, at the edge of the known world. This project lives on another edge.
> 
> _Сервер. Агенты. Панель. Три тела — одна цель._

## Что это

**Geryon Recon** — локальная распределительная OSINT-система для сбора информации из открытых источников.

Сервер раздаёт задачи агентам-воркерам, результаты собираются в веб-панели. Работает **локально**, внешние серверы не нужны. Каждый агент — **голова Гериона**: возьмёт задачу, выполнит, отдаст результат.

## Архитектура

* **`server/`** — FastAPI-сервер, оркестратор задач, хранение истории в SQLite.
* **`agent/`** — воркеры, выполняют задачи, собирают телеметрию железа.
* **`panel/`** — веб-панель управления на vanilla JS.

## Что нового в 1.3.0

* **Исправлена база данных**: восстановлена схема хранения (JSON) после случайного удаления, добавлены бэкапы.
* **Агрегация результатов**: родительская задача `username` теперь собирает результаты всех 35+ подзадач в единый список для панели.
* **Починена логика `recompute_parents`**: если часть сайтов недоступна (403 / Timeout), задача не падает в `failed`, а завершается в `done` с частичным результатом.
* **Новая навигация панели**: прямые пути `/menu`, `/panel`, `/about` вместо ссылок на статику. Корень `/` редиректит на меню.
* **Прогресс-бар**: сервер считает `progress_done` / `progress_failed` и отдаёт их фронтенду для плавного заполнения полоски.
* **WebSocket-уведомления**: панель обновляется мгновенно, без перезагрузки страницы (вместо тупого `setInterval`).
* **Глушитель favicon**: больше никаких 404 в консоли браузера.

## Безопасность (Важно!)

Начиная с версии **1.2.0**, система защищена API-токеном.
* Все критичные эндпоинты (регистрация агентов, heartbeat, отправка результатов, создание/удаление задач) требуют заголовок `X-API-Key`.
* Панель при загрузке запрашивает пароль и автоматически подставляет токен во все `fetch`-запросы.
* Настройки хранятся в файле `.env` (который игнорируется Git и не попадает в публичный доступ).

## OSINT-модули

| Модуль | Что собирает |
|---|---|
| `email` | MX, A-записи, Gravatar |
| `email_reg` | где email зарегистрирован (holehe) |
| `domain` | WHOIS, DNS, поддомены, SSL, HTTP |
| `username` | 35+ сайтов через распределенные подзадачи |
| `ip` | гео, ASN, PTR, RIR-whois |
| `phone` | оператор, регион, тип линии |
| `person` | поиск по ФИО в открытых источниках |
| `telegram` | проверка публичного аккаунта по @username |
| `geo` | координаты / адрес → адрес + что рядом (100 м) |
| `exif` | метаданные фото (GPS, дата, устройство) |

## Мониторинг железа (sysinfo)

Отдельный модуль `sysinfo` собирает состояние машины (CPU, GPU, RAM, SSD) через **LibreHardwareMonitor** (LHM).

Агенту **не обязательно** иметь LHM: если он не запущен, `sysinfo` вернёт `{"available": false, "reason": "..."}` и продолжит работу. Модуль был выбран для публичного индекса **XERJ Corpus Hub**.

## Установка и запуск

### 1. Подготовка окружения
Убедись, что у тебя установлен Python 3.10+.

```bash
pip install -r requirements.txt
```

### 2. Настройка `.env`
Скопируй файл `.env.example` в `.env` (в папке `server`):

```bash
cd server
copy .env.example .env   # Windows
# или
cp .env.example .env     # Linux/macOS
```

Открой `.env` и заполни:
* `GERYON_API_TOKEN` — придумай свой секретный ключ (латиница, цифры, спецсимволы).
* `GERYON_SERVER_URL` — оставь `http://127.0.0.1:5555`, если запускаешь локально.
* `DISCORD_WEBHOOK_URL` — если хочешь получать уведомления в Discord.

### 3. Запуск сервера

```bash
cd server
python server.py
```

Сервер начнет слушать `http://0.0.0.0:5555`. В логах должно появиться:

```text
[*] Geryon Recon — starting up...
[+] loaded 0 bots, 0 tasks from DB
INFO:     Uvicorn running on http://0.0.0.0:5555
```

### 4. Запуск агентов
Открой **второй терминал**:

```bash
cd agent
python agent.py --count 1
```

Агент зарегистрируется, и в логах появится:

```text
[+] little meepo 1 registered modules=['email', 'email_reg', 'domain', ...]
```

### 5. Панель управления
Открой в браузере: **http://127.0.0.1:5555**

При первом входе панель запросит **API-токен**. Введи тот же ключ, который указал в `.env`. Он сохранится в браузере.

*(Если ты уже вошел раньше, а сервер поменялся — очисти LocalStorage через F12 -> Application, чтобы ввести новый токен)*.

### 6. Мониторинг задач
* **`/menu`** — главное меню.
* **`/panel`** — сама панель управления агентами и задачами.
* **`/about`** — информация о проекте.
